## 漏洞状态全流程(重要!)

| 状态 | 含义 |
|------|------|
| 待审核 | 补天对新提交漏洞初审,避免向厂商转交无效漏洞 |
| 待补充 | 细节太简单/没截图/没链接,补充后再提交 |
| 审核不通过 | 见下方 5 个理由 |
| 审核通过 | 补天已审核通过,联系厂商中(可能数日);厂商未认领将转交监管部门 |
| 奖金确认中 | 厂商已确认有效,正在确认最终奖金 |
| 奖金已确认 | 奖金确认完成 |
| 待打款 | 等财务打款,一般**每周三** |
| 打款完成 | 确认银行卡到账 |

**审核不通过的 5 个理由**:
1. 漏洞无法复现
2. 漏洞真实存在但影响不大,实际危害较小
3. 漏洞属抄袭,或未经验证的提交
4. 无法联系到厂商,厂商太小(权重<1)或已停止维护
5. 与平台现有记录重复或互联网上细节已公开

**审核通过后厂商仍可忽略的理由**: 误归属(漏洞不属于该厂商)/ 漏洞重复 / 无影响

- 不通过原因查看: 个人空间 → 漏洞列表 → "审核不通过"后面的"原因"(鼠标悬停)
- 进度查询: 关注【补天漏洞响应平台】微信服务号 或 官网-个人中心-漏洞列表

## 选择挖哪些厂商

- **项目大厅**(/Reward/plan)可看: 专属SRC / 公益SRC / 未注册厂商
- 专属SRC: 厂商自定义奖励计划+可测范围+不同等级奖金,点厂商看具体计划
- 公益SRC: 按【补天奖励计划】(Help/plan)
- **新人建议**: 先从公益SRC或权重较低的互联网厂商入手,积累经验后再挑战专属SRC冲榜
- 更多福利: 活动中心 / 个人空间,关注【补天平台】公众号

## 报酬

- 公益SRC+未注册厂商: KB + 现金(见 Help/plan 定价表)
- **专属SRC: 全部现金**,奖金范围看各厂商奖励计划
- 现金: 每周三打款,48小时到账;KB: 审核通过后 7 天发放(个人空间看余额)

## 积分与排名

- **1KB / 5RMB = 1 积分**
- 低危且奖励 ≤1KB 的漏洞无积分
- 降级奖励不降积分: 中危1KB=2积分;高危1KB=4积分
- 单个漏洞积分 ≤1000
- 风云榜: 月度+总排行(积分最多/赏金最高/有效率最高)
- 月度荣誉榜: 荣耀个人/荣耀团队/跃秀新星,上榜有奖金
- 个人空间可看: 积分、称号、排名
